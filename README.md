# Our Place at Mickleton

A mobile-first family guest-book site for our caravan in Mickleton, County Durham.

## Features
- Responsive, phone-first layout
- Optimised WebP photo gallery and lightbox
- Family guest book with star ratings
- Share button for WhatsApp/messages
- Installable/offline-friendly PWA shell
- Optional shared reviews through Supabase

## Reviews
By default reviews are stored in the visitor's browser for preview/testing. To make reviews shared across all family devices, add a Supabase project URL and anonymous key in `config.js` and create a `reviews` table.

## GitHub Pages
Publish from the repository root on the `main` branch.
